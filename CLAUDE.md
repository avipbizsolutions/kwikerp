# KwikERP – working notes for Claude

Product: offline-first ERP for dairy/sweets businesses, built mostly by Atul
with Claude. Tenant #1 is Troika Dairy (Dugdh Dhara). AVIP Business Solutions
LLP owns the product and will sell it as SaaS, so nothing Troika-specific may
be hard-coded.

## Non-negotiable rules

- Every business table has `tenant_id`; row-level security uses `app.tenant_id`.
  The API connects as a non-owner role so RLS applies.
- Records a device can create use client-generated UUIDs. Never serial ids.
- Every syncable table has `server_seq` (trigger), `updated_at`, `deleted_at`.
  Deletes are soft.
- Configurable, never hard-coded: price levels (open-ended), customer
  categories, units, credit limits, Sahyogi commission per centre, rate charts,
  GST rates, document numbering.
- Document numbers: `<LOCATION>-<DEVICE>-<FY>-<seq>` per device and doc type,
  so offline tablets never clash.
- Credit control: customer limit overrides category limit; a bill beyond the
  limit becomes `pending_approval` and needs a manager decision (app, WhatsApp,
  or an offline one-time code).
- Accounts stay in Tally; KwikERP exports vouchers.
- Hosting: the Hostinger VPS (CloudPanel). Secrets only in environment
  variables, never in the repo.

## Conventions

- SQL: snake_case, schema `kwik`, money `numeric(12,2)`, quantities
  `numeric(12,3)`.
- Seed data is generated by scripts in `tools/` from raw exports in
  `db/seed/source/`; fix data in the source sheet, not by hand in the output.
- GST rates in the seed are provisional until the accountant confirms them.
