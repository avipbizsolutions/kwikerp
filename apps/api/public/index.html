Customer types

Each type sets the rates its customers are billed at and their default credit. A customer's own limit, when set, replaces their type's. Bills beyond the limit come to you for approval.

Rates are per piece / pouch / kg. Trays and boxes are set to piece rate × pack size automatically. One chart for all outlets. Today's rates keep running until the date above.

Item photos
Company photos, used on every tablet. A tablet can change its own (that tablet only).

Upload many: name each file by item code (2.jpg for Milk Gold H, 66.jpg for Paneer 180gm). Photos are cropped square and made small (about 20 KB), so tablets download them quickly and keep them offline.

Stock count
