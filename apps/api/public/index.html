KwikERP Head Office

Refreshes every 20 seconds. Credit bills over the customer's limit and stock adjustments wait here until you decide.

Limit for each customer type. A customer's own limit, when set, replaces their type's limit. A limit of ₹0 means every credit bill needs your approval. Leave the amount empty for no amount limit.
Makes a file to import in TallyPrime: Gateway of Tally → Import → Transactions. Bills paid in full go in as one sales voucher per outlet per day; each credit bill goes in separately against the customer, so dues match in Tally. Cancelled bills are left out.
Tally ledger names (set once; must match your Tally exactly)

{outlet} becomes the outlet code (e.g. "Cash - {outlet}" → "Cash - DD3"); {rate} becomes the GST rate.

First import only

Credit customers need a ledger in Tally before their bills can be imported. This file creates them under Sundry Debtors with bill-wise details on. Import it with Import → Masters; customers already in Tally are skipped.

User types

What each type of login may do. Changes apply when the person next logs in. Owner is locked.

Staff logins

Each login has a user type. Types that work at one location (Cashier, Store Manager, Dispatch) need the location.
